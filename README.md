# Dugan's Den — app releases

Installers for the Dugan's Den vendor app. Binaries and release notes only;
the source lives in a private repository.

- **Download page:** https://app.dugansden.com/download
- **Browser version:** https://app.dugansden.com — no install, but TCGPlayer,
  Alt and Card Ladder pricing need an installed app.

| Platform | File in each release |
| --- | --- |
| Windows 10/11 | `DugansDen_<version>_x64-setup.exe` |
| Android 8+ | `den-<version>-android.apk` |

`version.json` at the root of this repository names the current version and
the checksum of each file, so the app can check for updates.

Access to the app is by invitation. Alpha software: expect rough edges.
